# Pokémon Arena Mobile

Protótipo de jogo de batalha por turnos 3×3, inspirado na organização visual de jogos de arena, com interface mobile em português.

## Versão

Alpha 0.9 — seleção de 10 Pokémon de Kanto, formação de equipe de três por arrastar e soltar (drag and drop) ou toque, filtros por tipo, habilidades, energia, esquiva e batalhas contra o computador.

## Como executar

O jogo é estático e funciona sem backend. Abra `index.html` em um navegador moderno. Para iPhone, hospede o projeto em HTTPS (GitHub Pages ou Vercel), pois visualizadores internos de arquivos podem bloquear scripts.

## Publicação

O arquivo principal `index.html` da Alpha 0.9 precisa ser adicionado ao repositório para habilitar a execução. Ele contém os assets incorporados para funcionamento offline.

## Observações

Protótipo de fã, não oficial e não afiliado à Nintendo, Game Freak ou The Pokémon Company.
